# Benchmark evidence

These are historical synthetic measurements, not production latency guarantees. See the root reports for methodology, interpretation and limitations.

For public distribution, local home/workspace paths in text logs and metadata are replaced with `<home>` and `<workspace>`. Diagnostic launchers accept `CARGO` rather than embedding the original user's toolchain path. Timing samples, source hashes, outcomes and benchmark source archives are unchanged. Scripts archived as execution evidence may still require the original workspace layout; use the maintained `benches/` runners to reproduce experiments in a fresh checkout.
